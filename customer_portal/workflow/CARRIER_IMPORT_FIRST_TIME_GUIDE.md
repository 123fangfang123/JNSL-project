# 物流商运单导入 - 首次配置指南

## 📋 工作流程

### **首次导入某个物流商时**

1. **运行导入脚本**
   ```bash
   node tools/import-carrier-shipments.js <excel_file_path>
   ```

2. **脚本会自动识别物流商**
   - 基于 Excel 表头关键字识别
   - 显示识别结果

3. **显示当前配置的列映射**
   ```
   📋 当前配置的列映射:
      ✅ tracking_no ← 运单号
      ✅ transaction_id ← 客户单号
      ✅ shipment_status ← 状态
      ✅ dest_tracking ← 跟踪号
      ✅ delivered_date ← 到货日期
   ```

4. **您需要确认映射是否正确**
   - ✅ 表示该列在 Excel 文件中存在
   - ❌ 表示该列在 Excel 文件中不存在

5. **如果映射不正确或缺失**
   - 脚本会提示您提供正确的映射关系
   - 我会帮您更新配置文件

## ⚙️ 状态映射配置

### **HH Express 状态映射（特殊规则）**

HH Express 的状态格式特殊：`2026-08-10 23:16:07 / SHENZHEN / 已出仓`

脚本会自动提取最后的状态部分，并应用特殊规则：

| Excel 状态 | 数据库枚举 | 说明 |
|-----------|-----------|------|
| 已取消 | cancelled | 唯一明确映射的状态 |
| 其他所有状态 | shipped | 包括：已出仓、已入仓、运输中等 |

**示例：**
- `"2026-08-10 23:16:07 / SHENZHEN / 已出仓"` → `shipped`
- `"2026-08-11 05:58:50 / SHENZHEN / 已入仓"` → `shipped`
- `"2026-08-10 23:08:00 / SHENZHEN / 已取消"` → `cancelled`

## 💡 注意事项

### **1. 首次使用必须确认**
- 每个物流商第一次导入时，都会显示列映射供您确认
- 确保映射正确后再继续导入

### **2. 列名必须完全匹配**
- Excel 列名必须与配置中的完全一致
- 包括空格和标点符号

### **3. 状态值需要映射**
- 如果状态值不在映射表中，会保留原值
- 可以后续添加新的状态映射

### **4. 不会创建新记录**
- 脚本只更新已存在的 order_shipment 记录
- 如果 tracking_no 或 dest_tracking 不存在，会跳过
